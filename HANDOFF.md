### Фото поставщика до API — ждёт разрешения Росхолода

На rosholod.org фото лежат по адресу `/media/products_images/{GUID}/<файл>.jpg`, GUID совпадает с нашим `external_id`. Но имя файла неизвестно: список товаров их сайт грузит из `/api/`, закрытого для роботов в `robots.txt`; в HTML каталога — одно фото на страницу; в XML поле `СТ_АдресСсылкиURL` пустое у всех 15 017 карточек. **Без разрешения поставщика автоматический сбор не делаем.** С разрешением или архивом — команда загрузки через очередь, фото с `source = supplier` и `source_url`, чтобы API потом заменил их, а ручные остались.

### После запуска — дилерский портал из макетов (§21)

Лимит отсрочки и блокировка способа оплаты при просрочке, уровни дилерских скидок с прогрессом, счета и закрывающие в кабинете, шаблоны закупки, сотрудники и доступы, вход по SMS, подстановка реквизитов по ИНН.

## 5. Принятые решения, которые важно не сломать

**Импорт**
- Ключ товара — GUID поставщика (`products.external_id`), а не артикул: артикул пуст у 22% карточек и повторяется.
- Применение одной транзакцией; пробный прогон — та же транзакция с откатом.
- Отсутствие товара в снимке считается счётчиком `missing_runs`, а не сравнением времени; снятие — после 3 полных снимков.
- Остатки полного снимка переписываются целиком. Наличие — одним SQL-запросом; «снят с производства» он не трогает.
- Каждое поле товара заполняет один активный профиль (`OwnedFieldsGuard`).
- Импорт не пишет в поля из `locked_fields` (включая `retail_price` и `unit`), не меняет `slug`, витринные категории и ручные фото.
- Неизменившийся файл определяется ещё и по хешу (`import_runs.file_hash`); `ETag` сохраняется только после успешного прогона.
- Существующие склад и бренд с тем же названием связываются, а не создаются заново.

**Каталог и админка**
- Ручные правки — только через `SaveProductByManager` (замки, строка поиска, счётчики категорий, кэш). «Вернуть значение поставщика» снимает замок и обнуляет `source_hash`.
- Товары вручную не создаются; удаляет их мягко только администратор. Категории и бренды удаляет администратор. Импорт запускает менеджер, настройки профиля и поставщика — администратор.
- Кэш каталога сбрасывают `CatalogCacheObserver` (категории, бренды, склады) и действия менеджера; товары наблюдателем не охвачены сознательно.
- Смена `slug` ставит 301 без цепочек; новая страница освобождает свой адрес от старого редиректа.

**Витрина**
- На витрине только видимые, не снятые товары из включённых категорий (`CatalogQuery::listed`); выключенная категория скрывает свою ветку. После первого импорта витрина пуста, пока менеджер не включит категории.
- Все выборки витрины — через `CatalogQuery` и `ProductSearch`; цены — через `PriceResolver::forMany` в контроллере, шаблоны только показывают.
- Дизайн — из макетов `docs/design`; токены только в `@theme` файла `resources/css/app.css`; разметка собирается из компонентов, между страницами не копируется.
- Витрина работает без JS обычными GET-формами; Livewire — улучшение поверх.
- Деньги — только целые копейки (`Money`), проценты — базисные пункты (`Percent`); цены выводятся через `Typography::money` с неразрывными пробелами.

## 6. Подводные камни окружения

- **Окружение:** в каждом окне PowerShell сначала `. C:\Users\TLT-1\devtools\env.ps1`. Composer там вызывается через PHP, чтобы `^` в версиях не терялся.
- **База останавливается** при перезагрузке компьютера и после долгого простоя. Ошибка «конечный компьютер отверг запрос на подключение» — запустить `C:\Users\TLT-1\devtools\start-mariadb.ps1`.
- **Тесты** идут на MariaDB в базе `horeca_test`, SQLite запрещён. Полный прогон — около 1,5–2 минут.
- **Локальная база `horeca`** содержит реальный каталог Росхолода: все категории включены, 8 корневых отмечены «На главной», у 6 заданы иконки — это сделано вручную для просмотра витрины. Вернуть демо-данные: `php artisan migrate:fresh --seed`.
- **Просмотр витрины:** `.claude/launch.json` содержит конфигурацию `horeca` (`php artisan serve` на порту 8000 через портативный PHP).
- **Сертификаты HTTPS** для портативного PHP прописаны в `php.ini` (`devtools\php-8.4\extras\ssl\cacert.pem`); на Ubuntu это не нужно.
- **Фикстуры импорта** в windows-1251 и помечены двоичными; правка кириллицей — через `editRosholodFixture()` в `tests/Pest.php`.
- **`Http::fake()` добавляет заглушки к прежним** — подменять выгрузку между прогонами через `fakeRosholodFeeds()`.
- **Filament 5:** имя `$action` в замыканиях действий занято самим действием; опрос страницы делается на компоненте схемы (`->poll()`), а не на странице.
- **Архив дизайна** от заказчика лежит в корне (`Архив дизайна_сlaude design`) и исключён из git; распакованные макеты — в `docs/design`.
