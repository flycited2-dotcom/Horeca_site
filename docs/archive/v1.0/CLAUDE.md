# CLAUDE.md — правила работы над проектом horeca-shop

Полное задание: `TZ-horeca-shop.md`. Читай его перед каждым спринтом. Этот файл — постоянные правила, действующие всегда.

## Стек
Laravel 11 · Livewire 3 · Filament 3 · Tailwind 3.4 · Alpine 3 · MySQL 8 · Redis · PHP 8.3 · Node 20 (только сборка).
Деплой: Ubuntu VPS + HestiaCP, PHP-FPM, supervisor для очередей.

## Жёсткие правила

1. **Никаких заглушек.** Ни `TODO`, ни `// здесь будет логика`, ни «пример реализации». Файл создаётся целиком и рабочим.
2. **Не выдумывай API.** Не уверен в сигнатуре пакета — открой `vendor/` или документацию, не угадывай.
3. **Не ставь пакеты, которых нет в ТЗ**, без явного согласования. Если нужен новый — сначала объясни зачем, потом ставь.
4. **Бизнес-логика — в Actions/Services**, не в контроллерах и не в Livewire-компонентах.
5. **Деньги — `decimal(12,2)` в БД и целые копейки в PHP** (`App\Support\Money`). Флоаты в денежных расчётах запрещены.
6. **Импорт не имеет права знать источник данных.** Только через `SupplierFeedInterface`.
7. **Ручные правки менеджера священны.** Импорт не перезаписывает поля из `products.locked_fields`.
8. **N+1 запрещён.** Любой листинг — с `with()`. При сомнении включай Debugbar и проверяй.
9. **Каждая новая фича — с тестом.** Спринт не считается закрытым при красном `php artisan test`.
10. **Перед коммитом:** `./vendor/bin/pint` → `php artisan test` → `npm run build`.
11. **Миграции только вперёд**, `down()` реализован всегда, продовые данные не теряем.
12. **Никаких секретов в коде и в git.** Всё через `.env`, новые переменные дублируются в `.env.example`.
13. **SQLite в продакшене запрещён** (наступали на это в прошлом проекте).
14. **Тексты интерфейса — русские**, через `lang/ru/`. Кнопка называет действие: «Добавить в корзину», не «Отправить».

## Дизайн: коротко

Стальная палитра (`#F4F6F7`, `#D3D9DE`, `#15191D`), один акцент — синий `#0B5FFF`, наличие — `#1F8A5F`, «под заказ» — `#C2410C`.
Шрифты: Golos Text (заголовки) + Inter (текст), локально через `@fontsource`.
Карточки — плоские, с границей 1px, без теней по умолчанию; radius 6px.
Анимация — только как отклик на действие пользователя. `prefers-reduced-motion` уважаем.
Не используем: кремовые фоны, терракоту, glassmorphism, градиентные заливки, ALL-CAPS-надзаголовки, стрелки «→» в тексте кнопок.

## Порядок работы над задачей

1. Прочитать соответствующий раздел ТЗ целиком.
2. Кратко сказать, что именно будешь делать и какие файлы создашь/изменишь.
3. Сделать целиком.
4. Прогнать тесты и сборку, показать результат.
5. Сказать, что осталось незакрытым из раздела ТЗ, если что-то осталось.

Если требование ТЗ противоречит реальности (пакет не существует, схема не сходится) — **остановись и скажи**, не изобретай обход молча.
