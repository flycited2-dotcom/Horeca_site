# Выгрузки Росхолода: разбор реальных файлов

**Дата разбора:** 16.09.2026
**Файлы:** `https://rosholod.org/price-lists/Catalog.xml` (13,4 МБ, выгрузка от 16.09.26 05:00) и `https://rosholod.org/price-lists/OstatkiYandex.xml` (9,9 МБ, выгрузка от 16.09.26 10:00).
**Как считалось:** потоковое чтение XMLReader с перекодировкой из windows-1251, полный проход по обоим файлам.

Документ фиксирует факты. Решения, которые из них следуют, — в ТЗ (§6, §7, §8).

## 1. Общее

| | Catalog.xml | OstatkiYandex.xml |
|---|---|---|
| Кодировка | windows-1251 | windows-1251 |
| Корень | `yml_catalog date="16.09.26 05.00"` | `yml_catalog date="16.09.26 10.00"` |
| Пространство имён | нет | `https://www.1cteh.ru/xml/rosholod/ext_catalog_stock_yandex` |
| DOCTYPE | `shops.dtd` (внешний, не загружать) | `shops.dtd` |
| Карточка товара | `<ДетальнаяЗапись>` внутри `<offers>` | `<item xsi:type="item">` внутри `<offers>` |
| Товаров | 15 005 | 10 534 |
| Категории | 324 (`<category id parentId>`) | нет |
| Остатки | нет | `<stocks><stock>` |
| Фото | поле есть, пусто у всех | поле `URL` есть, пусто у всех |

**HTTP.** Оба файла отдаются с `ETag`, `Last-Modified` и `Accept-Ranges: bytes`. `Last-Modified` меняется несколько раз в сутки (15.09 в 22:54 МСК, 16.09 в 10:58 МСК) и не совпадает с временем формирования из атрибута `date`. Проверять изменения нужно условным GET по `ETag`, а не по часам.

## 2. Catalog.xml

### 2.1 Поля карточки

Все 14 полей присутствуют в каждой карточке; пустые значения записаны как `<Поле/>`.

### 3.2 Остатки

- `balance` принимает **только четыре значения**: `0` (8 939 записей), `несколько` (1 356), `в наличии` (1 275), `много` (1 142). Чисел нет. Значений «Мало», «Есть», «Ожидается» нет.
- `namestock` пусто у 7 930 записей: у товаров без остатков одна запись с пустым складом и `0`.
- Складов 20: Волжск (2 302 записи), Москва (ЦФО) 552, Новосибирск 469, Санкт-Петербург 189, Ярославль 179, Екатеринбург 170, Владивосток 138, Хабаровск 134, Ростов-на Дону 105, Омск 99, Челябинск 98, Тимашевск 69, Краснодар 54, Пермь 52, **Симферополь 47**, Нижний Новгород 36, Уфа 28, Тюмень 27, Ставрополь 23, Пятигорск 11.
- Складов в карточке: 1 — у 9 539 товаров, 2 — у 562, 3 и больше — у 433.
- `unitstock`: шт 12 601, кг 45, т 41, компл 19, м 2, пог. м 2, «100 шт» 1, м3 1.
- Сводно: хоть на одном складе есть — 2 184 товара, везде 0 — 8 350.
