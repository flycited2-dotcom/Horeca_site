# Handoff: интернет-магазин оборудования для HoReCa (дилерский портал)

## Overview
B2B-каталог профессионального кухонного и холодильного оборудования с дилерским кабинетом:
подбор по типу заведения, листинг с фильтрами, карточка товара, корзина со счётом для юрлица,
оформление заказа, личный кабинет организации, поиск по артикулам, сравнение моделей.
Референсы формата — rosholod.org, kolesa-darom.ru: сухой, плотный, «прайсовый» интерфейс
без маркетингового шума, где решение принимают по сроку поставки, артикулу и характеристикам.

## About the Design Files
Файлы в этом пакете — **дизайн-референсы, сделанные в HTML**. Это прототипы, показывающие
задуманный вид и поведение, а не продакшн-код для копирования. Задача — **воссоздать эти
экраны в существующей среде целевого проекта** (React, Vue, Svelte, Next.js и т. п.),
используя его принятые паттерны, компоненты и библиотеки. Если среды ещё нет — выбрать
подходящий стек и реализовать дизайн в нём.

`Карточка товара.dc.html` — один документ, внутри которого 13 секций-экранов, каждая с
подписью «Экран N · Название» и бейджем-идентификатором (`1a`, `4a`, `7a` …). Файл требует
лежащего рядом `support.js` (рантайм рендеринга шаблона) и открывается прямо в браузере.
`doc-page.js` нужен только спецификации.

## Fidelity
**High-fidelity.** Финальные цвета, типографика, отступы, состояния и копирайт.
Воссоздавать попиксельно, подставляя компоненты целевой кодовой базы там, где они
эквивалентны. Отрисованы все четыре диапазона: десктоп, планшет (экран 10) и
мобильный 390 (экран 14).

## Interactions & Behavior
- **Переход** для всех интерактивных состояний: `.15s ease`. Сдвиг элементов при hover запрещён.
- **Hover**: карточка — тень; основная кнопка — фон `#005C8C`; вторичная — фон `#E5F5FD`;
  нейтральная — рамка `#0072B0`; ссылка-название — цвет `#0072B0`.
- **Фокус**: `outline: 2px solid #0098EA; outline-offset: 2px` — виден всегда, скрывать нельзя.
- **Счётчик**: значение редактируется вручную, нормализуется при blur; 0 удаляет строку
  с возможностью отмены.
- **Загрузка**: скелет вместо спиннера везде, где известна структура результата.
- **Ошибки**: всегда с действием, никогда не «что-то пошло не так».
- **Адаптив**: четыре точки перелома — ≥1280, 1024–1279, 768–1023, <768. Полное описание
  перестроения каждого блока — в «Спецификация для фронта.dc.html», раздел 1.
  Перелом считать по ширине контейнера, а не по типу устройства.
  Высота кнопок и полей 44 px на всех диапазонах, включая десктоп.

## State Management
- `filters` — выбранные значения фильтров + флаг «только в наличии»; синхронизировать с URL
  (shareable-ссылка на выборку — обязательна для B2B).
- `sort`, `page` / `cursor` для листинга.
- `cart` — позиции (артикул, количество, цена на момент добавления), итоги пересчитываются
  на бэке: цена дилера персональная.
- `compare` — до 4 артикулов, флаг «только различия».
- `query` — нормализованная строка поиска + предложенные исправления.
- `account` — организация, договор, лимит отсрочки, список заказов с парой статусов
  (`payment`, `shipment`) — независимые перечисления.
- `auth` — гость | заявка на проверке | дилер; от этого зависит видимость цен.
  Заявка: `pending | approved | rejected`, корзина гостя переносится в аккаунт после одобрения.
- `pricing` — базовая цена, персональная цена, уровень скидки, оборот за квартал и порог
  следующего уровня (считает бэк, фронт только отображает).
- `credit` — лимит, использовано, доступно, наличие просрочки и дни; определяет
  доступность способа «Отсрочка» и показ баннера приостановки.
- Состояния запроса: `idle | loading | success | empty | error` для листинга, поиска, кабинета.

## Правила контента (соблюдать при реализации)
- Срок и наличие всегда конкретны: «Ожидается 28 сентября», не «скоро».
- Цена не прячется: если её нет — «Цена по запросу» и что произойдёт дальше.
- Нет фото — заглушка с типом оборудования, не пустой прямоугольник.
- Скидка показывается как «Ваша цена», а не как процент со звёздочкой.
- Никаких рейтингов, отзывов и таймеров: данных нет, доверие строится на сроках и документах.
- НДС 20 % — отдельной строкой; итог прописью в PDF-счёте.

## Доступность
- Контраст текста ≥ 4,5:1, крупных заголовков ≥ 3:1 — проверено по всем экранам.
- Цель нажатия ≥ 44×44 на всех диапазонах.
- Статус наличия дублируется текстом, не только цветом.
- Таблицы заказов и сравнения — настоящие `<table>` с `<thead>` и `scope`, не div-сетки.
- Фокус никогда не скрывается.
