# 21. Вне объёма MVP

Онлайн-оплата, интеграция с 1С:УТ, личные скидки клиента сверх группы, отзывы и рейтинги, блог, мультиязычность, калькулятор подбора кухни, фиды для Авито и Яндекс.Маркета, мобильное приложение, собственный склад и резервирование, электронный документооборот (УПД, ЭДО), автоподстановка реквизитов по ИНН, Meilisearch, автоматическое переписывание названий поставщика, CSP в блокирующем режиме.

**Дилерский портал из макетов** (`docs/design`, экраны 7, 15, 16) делается после запуска MVP отдельными спринтами по решению заказчика от 21.09.2026: лимит отсрочки и блокировка способа оплаты при просрочке, уровни дилерских скидок с прогрессом по обороту, счета и закрывающие документы в кабинете, шаблоны закупки, сотрудники и доступы компании, вход по SMS.

Всё перечисленное совместимо с текущей схемой БД и добавляется без её переделки.
